LunarRL: Teaching an Agent to Land

An AI agent learns to land a rocket in a 2D simulator.

Simulation only. Never tested on a real rocket.

Trained PPO
Random baseline

The idea

In 100 new test landings, the trained agent landed between the flags 98 times and crashed 0 times. A random agent crashed 90 times.

Open live demo ↗Code on GitHub ↗

Current limits

  • The simulator gives perfect measurements, with no sensor noise, no wind and no real hardware.

Measured results

What I built

  • Training and testing scripts for Gymnasium's LunarLander with Stable-Baselines3 PPO.
  • A fair comparison with random controls on the same 100 starting conditions.

The hardest problem

Proving it actually learned

One good landing proves little. I tested 100 new starts and counted every crash, including the bad runs.

What comes next

  • Add wind and turbulence.
  • Compare PPO with another algorithm, such as DQN.
