AutoPrompter

Improve a draft with Gemini, then get a second review from Cursor before sending.

Working in Aside on ChatGPT. Claude support is still being tested.

The idea

A personal browser extension for improving prompts inside ChatGPT and Claude. Gemini rewrites the draft, an optional local Cursor helper reviews coding prompts, and the user decides what to keep or send. A per-site Intercept switch lets quick questions go through normally.

View source on GitHub ↗

Current limits

  • ChatGPT improvement and Cursor review were tested in Aside. Claude rewrites timed out during testing.
  • Draft replacement can report a failed write when the editor changes paragraph spacing.
  • Requires a Gemini API key; Cursor review also requires the local Cursor CLI and helper.

What I built

  • A review panel with editable Gemini rewrites, assumptions, and changes.
  • An optional Cursor CLI helper for a second review of coding prompts.
  • A saved Intercept on/off switch beside Improve prompt, with manual improvement available when interception is off.

The hardest problem

Working with changing chat editors

The extension has to preserve the draft, handle browser-extension reloads, and confirm that an editable chat box actually accepted a replacement. Site-specific editor behavior is still being refined.

What comes next

  • Make draft replacement verification robust to paragraph spacing.
  • Improve reliability on Claude and test more browser versions.
