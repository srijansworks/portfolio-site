Engineering Experimenter

A debugging skill that won't blame hardware on a measurement it hasn't checked.

Built and in use. It caught the invalid measurement on the Tello project.

The idea

A Claude Code skill for investigating physical systems like drones and sensors. It checks that a measurement is valid before using it, and says what is still unmeasured.

What I built

  • A validity check that runs before any measurement supports a diagnosis.
  • A rule that every claim traces back to a log line, a line of code, or a script output.
  • Several competing causes held open, each with a test that could tell them apart.

Evidence & demos

The hardest problem

Most of the discipline only pays off on a real fault

A full investigation is overkill for a simple question. The hard part was getting the tool to use the full process only when a fault has an unknown cause.

What comes next

  • Test it on a case where the first hypothesis is correct, so it doesn't invent doubt.
